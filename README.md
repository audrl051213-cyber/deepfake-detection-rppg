'''
 ====================================================================
    PPG(광용적맥파) 기반 딥페이크 탐지 프로젝트 개요
  ====================================================================

  1. 프로젝트 목표
  --------------------------------------------------------------------
    - 사람의 심장 박동에 의한 미세한 피부색 변화(광용적맥파, PPG)를 이용
    - 진짜 영상: 주기적인 혈류 변화 패턴 존재
    - 딥페이크 영상: 이러한 생리학적 패턴이 없거나 불규칙
    - 이 차이를 딥러닝 모델로 학습하여 Real / Fake 판별


  2. 데이터 전처리 파이프라인
  --------------------------------------------------------------------
    [입력] 동영상 (.mp4)
      │
      ├─ (1) 프레임 추출
      │     - 영상 초반 3초 구간
      │     - 30 FPS로 샘플링 → 총 90장 추출
      │
      ├─ (2) 얼굴 크롭 (Face Crop)
      │     - 얼굴 영역을 사각형(네모)으로 잘라냄
      │     - 전체 프레임이 아닌 얼굴 부위만 사용
      │     - 딥러닝 모델이 스스로 중요 영역을 학습
      │
      ├─ (3) YCbCr 색공간 변환 + CbCr 15배 증폭
      │     - BGR → YCbCr 변환
      │     - Y (밝기): 그대로 유지
      │     - Cb (파랑 색차): (값 - 128) × 15 + 128 → 증폭
      │     - Cr (빨강 색차): (값 - 128) × 15 + 128 → 증폭
      │     - 증폭 후 다시 BGR로 복원
      │     - 미세한 피부색 변화가 과장되어 눈에 보이게 됨
      │
      └─ [출력] 전처리된 90장의 이미지 (얼굴 크롭 + CbCr 15x 증폭)


  3. 딥러닝 모델 구조
  --------------------------------------------------------------------
    - 입력: 전처리된 90장의 프레임 시퀀스
    - 활성화 함수: ReLU (Rectified Linear Unit)
    - 출력: Real(진짜) / Fake(딥페이크) 이진 분류

    [모델 아키텍처]
      CNN 기반
          - 각 프레임에서 공간적 특징 추출
          - Conv2D -> ReLU -> MaxPool -> ... -> FC -> Sigmoid


  4. 학습 환경
  --------------------------------------------------------------------
    - 플랫폼: Kaggle Notebook (무료 GPU 제공)
    - GPU: Kaggle T4 또는 P100 사용
    - 로컬 PC에는 GPU 없음 → 전처리만 로컬에서 수행
    - 학습/추론은 Kaggle에서 실행

    [워크플로우]
      로컬 PC                         Kaggle Notebook
      ─────────                       ───────────────
      영상 → 전처리 (ppg_preprocessing.py)
          → 전처리된 이미지 업로드 ────→ 데이터셋으로 등록
                                          → 모델 학습 (GPU)
                                          → 모델 저장 (.pth)
      모델 다운로드 ←──────────────────── 학습 완료


  5. 전처리 스크립트 사용법
  --------------------------------------------------------------------
    # 기본 영상 처리
    python ppg_preprocessing.py

    # 특정 영상 지정
    python ppg_preprocessing.py --video "영상파일.mp4"

    # 모든 딥페이크_*.mp4 일괄 처리
    python ppg_preprocessing.py --all

    # CbCr 증폭 배율 변경 (기본 15배)
    python ppg_preprocessing.py --amp 20

    # 설정값
    - 구간: 3초 (--duration 3)
    - FPS: 30 (--fps 30)
    - CbCr 증폭: 15배 (--amp 15)


  6. 출력 폴더 구조
  --------------------------------------------------------------------
    ppg_preprocessed/영상이름/
    └── CbCr_x15/  (90장) - YCbCr CbCr 15배 증폭 (BGR 복원 이미지)


  7. 핵심 기술 요약
  --------------------------------------------------------------------
    ┌─────────────────┬──────────────────────────────────────────┐
    │ 항목            │ 내용                                     │
    ├─────────────────┼──────────────────────────────────────────┤
    │ 탐지 원리       │ PPG (광용적맥파) - 심박에 의한 피부색 변화│
    │ 색공간          │ YCbCr (밝기와 색차 분리)                 │
    │ 전처리 핵심     │ CbCr 색차 성분 15배 증폭                 │
    │ 얼굴 크롭       │ 사각형 크롭 (모델이 알아서 학습)         │
    │ 프레임 수       │ 3초 × 30FPS = 90장                      │
    │ 활성화 함수     │ ReLU                                     │
    │ 분류            │ Real / Fake 이진 분류                    │
    │ 학습 환경       │ Kaggle Notebook (GPU)                    │
    │ 전처리 환경     │ 로컬 PC (CPU)                            │
    └─────────────────┴──────────────────────────────────────────┘

  ====================================================================
  '''
